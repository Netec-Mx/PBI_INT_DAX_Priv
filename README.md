# Power BI Intermedio: Modelado, DAX y Aplicación de Casos Reales

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Power BI Intermedio: Modelado, DAX y Aplicación de Casos Reales**. Aquí podrás fortalecer tus conocimientos mediante ejercicios prácticos enfocados en el modelado de datos, la creación de medidas DAX, la implementación de inteligencia de tiempo y el desarrollo de dashboards interactivos en Power BI.

Durante las prácticas trabajarás sobre un modelo de negocio previamente preparado, construyendo indicadores clave (KPIs), optimizando el análisis de información y aplicando las funcionalidades avanzadas de Power BI hasta finalizar con la publicación de un reporte en Power BI Service.

**Stack:** Microsoft Power BI Desktop · DAX (Data Analysis Expressions) · Power BI Service

---

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### [Práctica 1. Ejercicios prácticos con KPIs](Lab-1.md)

- **Descripción:** Construcción de medidas DAX, creación de una tabla calendario, implementación de inteligencia de tiempo, desarrollo de KPIs y análisis de indicadores comerciales mediante objetos visuales.
- ⏱️ **Duración estimada:** 40 min.

### [Práctica 2. Creación de un Dashboard](Lab-2.md)

- **Descripción:** Desarrollo de un dashboard interactivo utilizando drillthrough, formato condicional, marcadores, botones de navegación, páginas de detalle y publicación del reporte en Power BI Service.
- ⏱️ **Duración estimada:** 40 min.

---

## Requisitos

Antes de comenzar los laboratorios asegúrate de contar con:

- Microsoft Power BI Desktop instalado.
- Máquina virtual proporcionada para el curso.
- Archivos **Modelo-inicial.pbix** y **Modelo-desarrollado.pbix**.
- Acceso a Power BI Service para la publicación del reporte.
- Conocimientos básicos sobre Power BI y visualización de datos.

---

## Orden recomendado

1. Práctica 1. Ejercicios prácticos con KPIs.
2. Práctica 2. Creación de un Dashboard.
